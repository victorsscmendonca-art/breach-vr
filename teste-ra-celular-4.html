Seu protoboard, pela câmera

Este teste mostra uma etiqueta virtual ao lado de um marcador. Não existe modelo 3D do circuito nem reconhecimento dos componentes.

  1. Abra o marcador HIRO abaixo no Chromebook ou imprima-o com uma margem branca.
  2. Coloque-o ao lado do protoboard, imóvel. Mantenha a palavra HIRO voltada para você.
  3. No celular, toque em iniciar e permita a câmera. Enquadre o marcador inteiro.

Abrir marcador HIRO

É um marcador próprio de RA, não um QR Code comum. Ele deve continuar visível para a etiqueta aparecer.

Use o Chrome e um link HTTPS, como GitHub Pages. Não abra apenas o arquivo baixado ou dentro da prévia do ChatGPT. Precisa de internet para carregar as bibliotecas. O código não envia imagens a um servidor.
